# ExcelCreator v2.0

Вторая версия приложения на Qt для редактирования контактных данных в БД, которые ведутся в Excel-файлах.

## Что добавлено
- Многопоточная обработка (интерфейс не зависает)
- Понятное логирование результата обработки в реальном времени и в файл
- Пауза и возобновление обработки
- Обновленная валидация заполненных данных

## Технологии
- C++17
- Qt 6.11.2
- Многопоточность (std::thread, condition_variable)

## Сборка
Для работы exe файла без DLL требуется статическая сборка проекта.

## Рекомендации по работе с файлами
Для обработки файлов рекомендуется делать копию оригинального файла, так как программа редактирует файл по указанному пути.

## Описание классов
Class ExcelProcessor - предназначен для работы с файлом excel через COM-объекты и для чтения информации из файла.
Class Corrector - предназначен для редактирования полученных данных через регулярные выражения.
